# 手指接口

`Config::hand_control` 默认关闭。开启后，手指和主电机通过同一次 `Runtime::write()` 在 IO 线程顺序下发，共用命令期限、看门狗和故障锁定。

`Command::hand_enabled=true` 时填写 `hand_position`：固定 12 槽，0–100% 闭合度，每侧前 5 槽有效，第 6 槽（5/11）必须为零。`hand_kp/kd` 为仿真关节侧增益，有限且分别不超过 100/10；SDK 内保持关节侧力矩限幅。手指命令关闭或进入阻尼后保持最近目标；仿真使用原固定保持增益。停止/急停沿用 SDK 行为。

仿真还要求显式配置 10 个主动关节、四连杆标定、固定启动姿态及力矩上限。未开启动态手指时，原固定保持路径不变。

硬件路径只接受 SDK YAML 中显式选择 `aiq11-pro`、`EndEffectorMapping.type: LEGACY` 的三指手，检查发生在 SDK 初始化前。报文 `mode=0` 与参考 bridge 一致；硬件 LEGACY 使用手板位置控制，不采用仿真 Kp/Kd 限力矩。该接口不能用于单电机 EIRGRIPPER 的 0–1 rad 命令。**不得仅修改类型字段来绕过检查，必须确认实际设备及协议。**

非法值/维度、SDK 拒绝、迟到或阻塞下发都会故障锁定，不能由新的成功命令恢复。自定义 Backend 的 `writeHand()` 与 `write()` 一样，必须满足并发急停立即抑制的契约。

本轮只完成硬件后端编译、初始化前类型拒绝测试、假后端测试及代码检查，没有连接机器人；上层应用硬件运动入口仍禁用。实机通信与停机行为需独立验收。
