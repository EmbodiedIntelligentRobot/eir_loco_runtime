# 电机阻尼配置

`Config::damping_kd` 为默认阻尼，默认 5.0。可选 `motor_damping_kd` 按 `motor_names` 顺序指定每个电机的阻尼；不是 SDK 槽位顺序。为空时，runtime 构造阶段展开为统一默认值，可通过 `runtime.config().motor_damping_kd` 查询最终数组。

```cpp
Config config;
// 其他机型/后端配置略。
config.motor_names = {"motor_b", "motor_a"};
config.motor_slots = {3, 1};
config.damping_kd = 5.0;
config.motor_damping_kd = {0.5, 5.0}; // SDK 槽 3 为 0.5，槽 1 为 5.0。
```

默认值和所有逐电机值必须有限且大于零；非空数组长度必须与电机数量一致。配置错误在后端启动前拒绝。

显式测试选项 `Config::passive_observation=true` 将所有身体电机的 Kp、Kd、目标速度和前馈力矩强制置零，从首条启动命令生效，并拒绝 `setDamping(false)`。此模式允许传入零阻尼，仍拒绝负值/非有限值，并要求关闭手部控制及静态手指保持。普通配置的正阻尼校验不变。该模式仍初始化 SDK、发送零增益命令，机体需要外部支撑；故障和退出仍调用原 SDK 急停接口，不承诺该接口内部也保持零增益。

逐电机阻尼作用于 `start()` 的第一条阻尼命令、`setDamping(true)` 和阻尼模式中的 `write()`。阻尼命令的 Kp、目标速度、前馈力矩为零，未映射槽位保持禁用。`Running` 模式仍使用调用者的 `Command::kd`。故障或退出时调用的 SDK `Estop()` 由后端实现，不通过此阻尼配置重新发送普通命令。

`Config` 增加字段后，依赖它的应用和共享库需一起重新编译、部署，不能混用旧应用二进制与新 runtime 库。
